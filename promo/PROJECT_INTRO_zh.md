# AgentZero：没有操作系统的笔记本，当作 AI 的裸机身体

> 一台 2009 年的报废笔记本，连 Linux 都装不上。我们不给它装系统，而是从零手写一个 x86 裸机内核，
> 让它跑一个真实动物的完整大脑、用自己的神经网络画出你的脸、被 AI 经网络直接操控。
> 开源（MIT）：https://github.com/WalterWood1995/AgentZero

## 它是什么

AgentZero 是一个为 AI Agent 建造的**裸机内核**：没有操作系统、没有驱动栈、没有运行时、没有一行 C——
一个从零手写的 32 位 x86 内核直接驱动硬件，Agent 通过网络用一套 **ring 0 指令集** 读写这台机器的
CPU、内存、PCI 配置空间、I/O 端口和帧缓冲。机器本身只做三件事：开机从网络拉内核、执行指令、把结果写回网络或屏幕。

它的起点是一台 2009 年的华硕 K50IJ（Core 2 Duo T4300，2 GB 内存，GMA 4500M 集显，Atheros AR8131 网卡，德语键盘）。
它的 SATA 控制器让任何 Linux 都在开机探测存储时卡死，常规意义上已经报废。我们干脆**绕开存储**：
PXE 网络启动，内核从不触碰硬盘，机器反而稳定得像新的一样。

## 它已经做到的事

- **开机即硬件自报**：PCI 自举扫描把真实芯片组列在屏幕上；开发机经 UDP 远程读 CPUID、RTC、PCI、物理内存、I/O 端口，带确认闸的写原语防止误操作。
- **老机自己算数学**：定点傅里叶级数在它的 CPU 上逐帧画出世界地图和人像。
- **裸机聊天终端与网页阅读器**：老机键盘打字、屏幕显示 AI 的回答和维基页面。
- **60 fps 游戏机**：PS/2 按键状态表、PIT 定时帧循环、Pong 与双人格斗。
- **线虫大脑**（本片第一章）。
- **实时 ASCII 头像与老机自己的神经网络**（本片第二章）。

## 第一章：一个真实动物的完整大脑

秀丽隐杆线虫（*C. elegans*）是唯一连接组完整公开的动物：302 个神经元、约一万个突触
（OpenWorm 数据表，MIT 许可，底层来自 White 1986 / Varshney 2011）。

- **数据**：开发机把连接组整理成 8 KB 的压缩稀疏表，烧进内核镜像；开机时内核展开为 400×304 的 int16 稠密矩阵。
- **计算**：每帧用 SSE2 `pmaddwd` 跑两步积分发放更新——突触求和、泄漏、阈值、不应期、发放适应、全局抑制——
  每秒 120 步，全部在这颗 2009 年的双核 CPU 上。Python 有一份逐位一致的参考实现，内核的两条计算路径
  （SSE2 稠密、标量稀疏）与它对账 **maxdiff = 0**。
- **模型输出即动作**：A 类与 B 类运动神经元的发放差决定倒退或前进；96 块体壁肌肉行的膜电位决定身体每一节的弯曲；
  触觉神经元 ALM/AVM/PLM 接收戳击和皿壁，化学感觉神经元 ASEL/ASER/AWC 接收食物浓度的升降，咽部神经元 NSM/MC 在食物上被驱动——
  于是它倒退、前冲、循着梯度趋食、减速、用咽泵进食。
- **可视化**：屏幕右半把 302 个神经元画成分层网络，突触是连线，神经元发放时它的出边亮起——你看到的是活动在真实连接组里传播。

诚实说明：这是**定性的"漫画版"**。连接是真实的，神经元动力学是简化的 LIF 模型；原始权重直接用会要么全哑要么雪崩，
所以加了行归一、发放适应、全局抑制三项稳态机制，以及三条有文献依据的建模假设（Chalfie 1985 触觉逃逸回路、
前进/倒退指令神经元互抑、Gray 2005 失去气味掉头回路），全部写在数据说明里。

## 第二章：它用自己的神经网络画出你的脸

开发机的摄像头拍到人脸，只把灰度格子经 UDP 送到老机（一帧约 4 KB）。**字符由老机自己算**：
内核里跑一个极小的 MLP——每格取 3×3 邻域 9 个灰度值，32 个隐藏单元，输出 16 种字形——int16 定点，权重只有 1.8 KB。
每帧 12288 个格子逐格推理，全部在 ring 0 汇编里，真机 10 帧每秒；结果与 Python 参考**逐格位精确一致**。
屏幕右侧面板实时展示模型的运算过程：探针格的输入、隐藏层、输出分数、W1/W2 权重图、逐帧轮播的乘加。
同一块屏幕还能把你的脸和线虫大脑并排：你的动作成为它的感觉输入。

## 为什么这样做

- **去掉软件层**：没有 OS、没有驱动、没有运行时，Agent 直接面对硬件。效率和可理解性都来自这一点。
- **老机器 = 网络可控的裸机算力**：一台"报废"的机器，只要 CPU 和网卡还活着，就能当成 AI 的身体和计算单元。
- **本地神经网络即动作**：模型跑在老机 CPU 上，输出直接变成动作（线虫的运动、屏幕上的字符），不经过任何中间层。
- **全程可验证**：每一项计算都有 Python 真值对账（maxdiff = 0、逐格位精确），每一项行为都有 QEMU 无人测试。

## 怎么跑

- 工具链：NASM + QEMU（Windows 绿色版即可）；`bash build.sh` 一键构建，`WORM=1 bash build.sh` 构建线虫培养皿内核。
- 开发：`python worm/brain_qemu_test.py`（对账）、`python worm/worm_qemu_test.py`（行为验收与录帧）。
- 真机：`pxe_server.py`（proxyDHCP + TFTP）常驻，老机设网络引导优先，开机即进内核；换镜像只是复制一个文件。

## 下一步
